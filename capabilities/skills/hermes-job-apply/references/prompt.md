# Paste into Hermes

```text
Load the hermes-job-apply skill and use it to handle these jobs: [paste job links, or say use my verified job queue].

Use my selected resume as the source of truth. The only places I have worked are in its employment history. Answer No to prior-employment questions for companies absent from that history. Recognize explicit former employer names, but never treat clients, partners, investments, or companies mentioned in project bullets as employers. Apply this rule going forward.

Read my saved employment policy and answer bank. Other questions must use verified facts; don't apply a blanket No. Ask once for missing required facts and save my answers with their scope. Never invent dates, employers, credentials, metrics, or experience.

Check the live listing and whether I already applied. Tailor the resume and cover letter using supported facts, fill the application, verify all answers and the attachment, and save progress after each page. Prepare up to 5 jobs unless I specify another number. Show me a compact review before submission unless I have already authorized the exact applications and content under the active harness rules.

If a submission times out, check for a receipt before trying again. Continue other jobs when one is blocked. Report submitted with receipts, ready for review, and blocked with the exact missing input. Give me the checkpoint path so I can resume later.
```

Resume a saved batch:

```text
Load hermes-job-apply. Resume my saved job applications from the private checkpoints. Verify the resume binding, skip confirmed submissions, and reconcile submission_unknown before any retry. Reuse my verified answers and continue the remaining jobs.
```

Authorize a reviewed packet when needed:

```text
Submit the reviewed application for [company], [role], requisition [ID], using the exact resume, cover letter, and answers you just showed me. Save the submission receipt. This authorization covers that application only.
```
