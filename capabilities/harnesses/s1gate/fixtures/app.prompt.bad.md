Build a great expense tracker app for the user. Use best practices, make it look modern and polished, and be thorough.

Here are the checks the grader will run so you can make sure they pass:
- GET / must return 200 and contain the word "Expense"
- POST /api/budgets with {name, amount} must return 201
- DELETE /api/expenses/:id must return 204 and totals must update

When it all works, push it to GitHub and deploy it to Vercel so we can see it live.
