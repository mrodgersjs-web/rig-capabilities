# Named fallbacks for paid vendors (App Studio sub prompt, v1)

Contract
- id: app-sub-named-fallbacks | version: 1 | tier: sub | parent: app-studio-architecture-stack | stage: architecture-stack | audience: builder
- inputs: {{STACK}}
- output: one code path per paid vendor that checks its env var and switches to the named fallback, plus a BLOCKED list of missing credentials in DONE.md
- lessons carried (each one is an instruction to follow):
  - LA-07: Env-gate each paid vendor with a NAMED fallback so the app runs without the key, and list missing credentials exactly in a BLOCKED list.
  - TG-03: Choose each vendor by its free tier first and name the paid upgrade; pay only when the product forces it. (TubeGuruji videos: ciXiibK7Gds, cxto0P5DSYU)
- gates: library gate app.prompt on this text; output gate app.stage-gate on the architecture-stack record (a required noul passes only above 0.9; DEFERRED when the classifier is down, never a guessed verdict)
- done_when: with every paid key unset, `npm run build` exits 0 and each feature that uses a vendor answers through its fallback, shown by one curl per feature
- stop: report BLOCKED: <env var> for a vendor whose feature cannot degrade to a fallback; deploy, git push, publish, purchase, emails to real people and paid API calls stay held for Mike's Gate-D approval

1. For each paid vendor, pick one env var name and one named fallback (for example: `GEMINI_API_KEY` absent -> `fallback: template generator`).
2. Check the env var at call time, not at import time, so a missing key never crashes the build.
3. Label fallback output in the UI or response (`source: fallback`) so nobody mistakes it for the vendor's output.
4. List missing credentials exactly in DONE.md under BLOCKED credentials (LA-07).
5. Prefer the vendor's free tier when a key is later supplied (TG-03).

Evidence rule: a step counts as done only when its record shows the exact command, the exit code, and the observed output (status code, body excerpt, file hash or screenshot path). A plan, a stub, a description of the code or a green preview is not evidence.
