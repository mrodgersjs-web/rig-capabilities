## Anti-patterns for this sub-topic
- Low-resolution or badly cut-out photos left in the layout. CLAIM(9eJYjNGeIOM@02:22)
- Cramming a compound grid, or locking the golden ratio. CLAIM(gUzkRue28VI@06:18, gUzkRue28VI@03:37)
- Hand-nudging a list instead of nesting auto-layout groups. CLAIM(guYN5LaAcS8@00:40)
- Equal print margins, in the Flux grid lesson, or guides fit to the page edge. An Envato booklet demo does set equal margins; see disagreements. CLAIM(wIabVp0Hh8U@09:56, wIabVp0Hh8U@12:38, SbEy7hdIJpc@01:25)
