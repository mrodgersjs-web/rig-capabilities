# Composition prompt layer

These are **draft** meta/subprompt contracts for the read-only mission
composer. The task prompt comes from the existing versioned
`capabilities/prompts/registry.json`; all current entries there are drafts.
Nothing here is production-calibrated or automatically dispatched.

The packet records exact file hashes. Promptfoo's offline routing suite checks
selection and abstention only. Promotion needs a saved, model- and
dataset-bound outcome evaluation of a real runtime artifact, plus independent
verification. Aside transcript probes are candidates for that later eval, not
proof that a prompt achieves a coding outcome.
