# Stage record with Evidence block (App Studio sub prompt, v1)

Contract
- id: app-sub-stage-record | version: 1 | tier: sub | parent: app-studio-builder | stage: all | audience: builder
- inputs: the stage name, {{FIRED_LESSONS}}
- output: .app-studio/stages/<stage>.md
- lessons carried (each one is an instruction to follow):
  - LA-21: Classify a check that could not run (missing tool, dependency or credential) as BLOCKED with the missing piece named, never as FAILED or PASS.
  - LA-34: Compare each run's duration and evidence with the work it claims; a multi-phase build that completes in seconds, or evidence hashed from placeholder strings, is a stub and not a result.
  - BENCH-03: Record a receipt or `not applicable: <reason>` for every fired lesson in the stage record. (evidence: fired lessons LA-06 and LA-09 had no receipt in either run on 2026-09-28 and the lesson validator exited 2)
- gates: library gate app.prompt on this text; output gate app.stage-gate (a required noul passes only above 0.9; DEFERRED when the classifier is down, never a guessed verdict)
- done_when: each record has the six sections below and every claim has a command in its Evidence block
- stop: write Status: BLOCKED with the missing piece when a claim cannot be proven; deploy, git push, publish, purchase, emails to real people and paid API calls stay held for Mike's Gate-D approval

Write .app-studio/stages/<stage>.md with:
1. `# Stage <stage>` and what it had to deliver.
2. Delivered: one line per claim.
3. Evidence: a fenced block per claim with `$ <command>`, `exit <code>`, and the observed output excerpt.
4. Lessons: each fired lesson id with the command that satisfied it, or `not applicable: <reason>`. Missing receipts for LA-06 and LA-09 failed the lesson check on 2026-09-28 (BENCH-03).
5. Blockers: each BLOCKED item with the missing piece (LA-21).
6. Status: DONE, HELD or SKIPPED, with the reason. A stage finished in seconds needs evidence that explains it (LA-34).

Evidence rule: a step counts as done only when its record shows the exact command, the exit code, and the observed output (status code, body excerpt, file hash or screenshot path). A plan, a stub, a description of the code or a green preview is not evidence.
