# Great example - web-imagery-provenance

The asset record for the Northwind Billing page, held at assets/SOURCES.md and complete
before handoff.

What makes it excellent:

1. One row per asset, and the licence cell is never empty. Columns are: filename, role on
   the page, source URL, author or rights holder, licence class and version, date
   retrieved, model/property release status, edits applied, and who signed off. Eleven
   assets, eleven rows, zero blank licence cells.

2. Licence class recorded precisely rather than as "free". Two rows read CC0 1.0 with the
   deed URL. One row reads Unsplash Licence with the date retrieved and a note that the
   licence was read on that date. One row reads "client-owned, written confirmation
   2026-03-04" and names the person who sent it.

3. The editorial trap was caught before shipping. The first candidate for the proof face
   was an editorial-only photograph of a real executive at a conference. The record marks
   it editorial-only and therefore not usable on a commercial page. It was replaced with a
   commissioned shot carrying a signed model release, and the rejected row stays in the
   file with the reason, so the same photo is not re-proposed next quarter.

4. The generated asset is fully attributed as generated. The onboarding diagram is marked
   AI-generated with the tool name, model version, the verbatim prompt and the generation
   date, plus a line confirming the tool's terms permit commercial use and that the output
   is not presented as a real person or a real product screen.

5. Release coverage is stated rather than assumed. Every photograph containing a
   recognisable person has a model release row with a reference. The one photograph with a
   third-party mark visible in the background is cropped to remove it rather than used as
   is.

The result to beat: a reviewer can pick any file on the page, read its row, and answer
"who owns this, what may we do with it, and what is the evidence" in under thirty seconds.
