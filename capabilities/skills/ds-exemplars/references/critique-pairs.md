# critique: looks like / does not

Owning main skill: ds-critique. Every row paraphrases a good-versus-bad contrast a creator showed, cited to the moment. Use as calibration before judging a screen; a card is only reusable as a visual reference after Jev ui.design scores the good side above the bad side.

| # | looks like (good) | does not (bad) | why | citation |
|---|-----|----------|-----------|------------------|
| 1 | Primary color only on the submit control | Same pink on icon, label, outline, header, and minor links | If every element shouts, none can lead | CLAIM(XZf5A0wcruE@01:00) |
| 2 | Link underlined or otherwise distinct from placeholder | Link set in the same style as placeholder text | The alternate path is invisible | CLAIM(XZf5A0wcruE@02:16) |
| 3 | One large sign-in button, register as small text | Two buttons of equal size and weight | The user has to guess which action the page wants | CLAIM(XZf5A0wcruE@02:44) |
| 4 | Icon, title, and subhead in one even lockup | Icon hovering just close enough to look accidental | Proximity either groups or it does not | CLAIM(XZf5A0wcruE@04:12) |
| 5 | Labels above fields, different from placeholders | No labels, placeholder doing the label's job | States and roles must be readable without guessing | CLAIM(XZf5A0wcruE@03:31) |
| 6 | Charts and tables as the focal point, chrome quiet | Giant sidebar and title bar outranking the data | A tool exists to be used, not admired | CLAIM(XZf5A0wcruE@06:31) |
| 7 | Charts in distinct value colors | Every pie, bar, and card in brand green | Shared hue hides which metric matters | CLAIM(XZf5A0wcruE@07:45) |
| 8 | Notification badges readable against their ground | Brand-color badges that disappear into the brand field | A badge that cannot be seen is not a badge | CLAIM(XZf5A0wcruE@08:33) |
