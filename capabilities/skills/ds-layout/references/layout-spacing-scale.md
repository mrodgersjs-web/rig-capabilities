## Anti-patterns for this sub-topic
- Clustering a button with body copy, or spacing related items so far the group breaks. CLAIM(EFf9jBs2yfU@03:45, cf95Z7Ngg8k@02:52)
- Using one spacing number for every relationship. CLAIM(cf95Z7Ngg8k@04:37)
- Low-resolution or badly cut-out photos left in the layout. CLAIM(9eJYjNGeIOM@02:22)
- Hand-nudging a list instead of nesting auto-layout groups. CLAIM(guYN5LaAcS8@00:40)
