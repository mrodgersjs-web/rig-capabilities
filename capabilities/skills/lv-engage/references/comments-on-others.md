# Comments on other people's posts

The outbound half of this stage: a comment is a billboard in front of someone else's audience [engagement-comment-led, Clark in BMfXeo02bvo]. It is content, and content rules apply: receipts only, lane voice, Jev gate before it leaves.

## The three-part comment

1. **Validate the point, by name.** Reference one specific detail in the post text: a number, a named system, a decision. Never a generic opener.
2. **Add exactly one insight the author did not make.** This is the payload. A measured delta, a named framework, a source, or one operator experience with a real receipt [comment-ambassador, engagement-comment-led].
3. **Optionally point to Mike's related post as a complement**, never a correction, and only inside the link caps [engagement-comment-led].

Worked shape (Firth's template, adapted): "This is spot on, <name>. I'll add that <one original insight>." Ends with a question that needs their expertise when the thread invites it [engagement-comment-led, MnQc73VYbJ0].

## Style rules

- Positive only. Never correct, pitch, one-up, or play contrarian; nobody engages a negative Nelly on someone else's post [comment-ambassador, engagement-comment-led].
- Never self-introduce. Never mention RIG, never name-drop Mike, in a link-free comment [comment-ambassador].
- Length varies: 1-3 sentences (under 420 characters) for the ambassador style; 2-6 sentences for sweep mini-posts. Uniform length across a batch is a detection vector, and LinkedIn hashes repetitive text blocks [comment-ambassador, borrowed-attention].
- Show the evidence, never state the conclusion you want the reader to draw; self-reached conclusions land faster (Kallaway, cuVyTmbOZjk) [engagement-comment-led].
- On new-job or milestone posts, almost every comment is one-word congratulations. A concrete question ("what is one thing that helped you land it?") stands out and opens a follow-up (Jeff Su, CwjwnHJE5sU) [engagement-comment-led].
- When amplifying, commentary-reshare beats a naked repost: add something from your own experience (Richard Walls, XmcUddcabsY) [engagement-comment-led].
- Read the whole post before commenting; the comment must reference a real point in it [lucy-skills/linkedin-activity] (job lane).

## Banned

- Generic praise openers: "Great post!", "Love this!", "Couldn't agree more.", "Spot-on", "Nailed it" [alfred-comment-engagement].
- Any AI-written or template-stamped comment [viral-core, Clark in 8nBIAUSIRnQ].
- Self-promotion outside the caps, corrections of the author, invented numbers or clients [comment-ambassador, viral-core].
- Amplifying off-site links others drop on Mike's own posts [engagement-comment-led].

## Link caps (a comment with a link is a promotion)

Max 3 link-bearing comments per sweep, at most one carrying a site link, never two link comments inside the same hour, never on a day a follow batch runs behind the sweep [engagement-comment-led]. A burst-link pattern suppresses the very post being promoted, so the safer read is: one link per sweep unless Mike says otherwise.

## Gate

Every comment goes through `rig-s1gate check comment.linkedin` before it leaves this stage. DEFERRED keeps it staged. An advisory PASS is not permission to post; the lane's approval rule decides that [viral-core].
