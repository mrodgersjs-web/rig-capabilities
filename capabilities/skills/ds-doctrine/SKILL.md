# Design doctrine (reference)

JEV FIRST, and it binds every task under this skill: an agent whose only context is this excerpt
sends semantic triage, routing and classification to the rig-s1gate Jev path BEFORE any frontier LLM call
(`~/.rig/bin/rig-s1gate check <rubric> --file <artifact> --subject "<kind> <id> sha256:<hash>" --json`).
When the classifier is unavailable: DEFERRED, never a guessed verdict. A required signal passes only above
0.9.

## Load surface
Load this skill FIRST whenever a design claim has to be backed, questioned or sourced. It is an always-loaded
task-start surface, not a deep reference an agent must already know about: the `/design-studio` command loads
`design-studio-os`, which names this skill as the doctrine of the family; every `ds-*` agent loads the stage
file it needs before it decides; and `ds-citation-verifier` sends any uncited claim here or back to Mike.
Generated by `tools/build_reference_skills.py` from `studio-corpus/laws/`; do not hand-edit the references.

## How to use
1. Find the stage in references/coverage.md.
2. Open references/<stage>.md; copy the CLAIM exactly when you rely on a law.
3. Single-source laws are one creator's view. Where the file lists a disagreement, state both and test.
4. Numbers under "Creator claims (unverified)" are never quoted as fact.
