# 12-surface register map (v5.2)

Base fingerprint + per-surface register deltas. The engine surface ids are in
`rig_comms/surfaces.py`; registers are the voice identity the draft wears.

| Register | Engine surface | Delta vs base fingerprint |
|---|---|---|
| operator / LinkedIn | linkedin | base register, full stop; compression hardest here; hooks mandatory |
| Substack-essayist | substack | longer architectural sentences allowed (band 4 toward hi end); receipts density up |
| email-work | emails | WMAQO skeleton; autonomy-preservation dominates; no hook theatrics |
| recruiter-professional | resumes | zero adjectives; numbers + verbs only; signature vocab drops (median/deviation off-register) |
| job-seeker | resumes (cover/DM variant) | recruiter register + one human line max |
| screenwriter | film-scripts | scene economy; dialogue registers per character; no author voice on the page |
| novelist | novels | character-registered voices; author fingerprint only in narration spine |
| songwriter | songs | EAS layer above fingerprint; banned-word list still applies to lyrics |
| engineer-spec | specs | fingerprint EXEMPT for wound/hook axes; clarity mechanics only |
| prompt-engineer | prompts | determinism > style; AntiSlop applies; no persuasion devices on the model |
| code-documenter | code | naming discipline is the voice; commit messages: imperative, why not what |
| intimate / James | love-notes | PRIVATE register — never federated, never scored by machine, never in any corpus |
