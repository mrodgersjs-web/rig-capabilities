# Twenty source-grounded meta-skills

These twenty routers are newly composed for the portable daily package. They are not twenty pre-existing original skills discovered elsewhere. Each delegates to concrete steps and subskills. They add routing instructions, not an executor, installed GrokBot feature, live schedule, authenticated service, or authority to apply.

Capability discovery used capabilities_search for job applications, employer/interview/portfolio research, JEV/Aside and SlopMonster. Canonical results were read before composition. The broad Aside search did not return a specific canonical Aside CLI skill; its integration therefore relies on the separately inspected specialist adapter, not an invented CLI capability. SlopMonster was discovered as an installed Hermes skill, not a canonical original.

## Authority exclusions

Historical Traject compensation figures, personal tokens, private paths, SQLite/Gmail authority, outreach permissions, automatic lesson promotion and old quotas are not imported. Airtable remains the named authoritative tracker, the daily profile remains disabled until explicitly configured and armed, and each application requires current specific authorization. Existing documented public-source research does not establish Mike's contribution. JEV is a typed reviewer, not a chat model or approval authority. Image gates require actual sanitized page pixels and original provider receipts.

A missing step link, unavailable Aside/JEV adapter, unverified schema, or unsupported native import is reported as a hold. Structural catalog validation only proves that the hierarchy resolves. Live operation requires the relevant real host/tool receipts and independent review.
