# Compose coding missions from the capability estate

## Intent

Mike wants to state a coding outcome in natural language and have the system
pick the relevant meta-skill, agent, subagent, and prompt hierarchy, using
RIG Memory OS and weekly evidence/evaluation to improve the choices.

## Slice delivered

- Read-only, hash-bound mission proposal over the live capability index and
  additional OMP/Prime agent roots.
- Three-level agent proposal and meta/task/subprompt proposal.
- Authenticated Memory OS package metadata, with degraded/no-fallback state.
- CLI and MCP entry points over the same composer.
- Deterministic unit and Promptfoo routing regressions.
- Weekly public-source metadata staging and local regression report, with no
  automatic promotion or dispatch.
- Local OpenJev shadow routing, a fail-closed completion gate candidate, and
  an evidence plan for LAYA/OpenJev text and image evaluation.
- A weekly task heartbeat that runs the scout/eval and reports only actionable
  deltas; it cannot promote assets.

## Boundaries

This slice does not claim every installed agent is runtime-connected, that a
draft prompt improves an outcome, or that a routed agent executed. Live adapter
receipts, independently labelled real-task outcome evaluations, and model
calibration are subsequent gates. Jev cannot certify DONE from its own answer.
No push,
publish, deployment, credential change, deletion, or private-data export.
