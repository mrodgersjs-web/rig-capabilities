# Offer Page

Purpose: one offer per page, three benefits, three-step plan, feature check near the decision, about-page formula, homepage teases.

Load when: the task touches this part of conversion copy, or a ds-conversion-copy critique names it. Part of `ds-conversion-copy`.

## Checklist
1. Work through every law below against the current artifact before calling the sub-topic done.
