# Big-tech loop prep: the months-long campaign

Purpose: turn the target-company list into a dated, budgeted preparation campaign across the four
big-tech round types, with behavioral and English prep included.

When to load: when starting or rebuilding interview preparation, when a round type needs a drill
plan, and when a candidate is preparing for a loop they have not confirmed with an insider.

## Step checklist

1. Define the goal and write the target-company list before studying; the list sets the
   requirements. CLAIM(2Xqu_GNvnxg@00:59)
2. Set a start and end deadline and a fixed daily budget (2-3 hours is the campaign assumption).
   CLAIM(2Xqu_GNvnxg@01:21) CLAIM(2Xqu_GNvnxg@01:44)
3. Share the preparation publicly as you go: momentum, feedback, and it helps other candidates.
   CLAIM(2Xqu_GNvnxg@01:58)
4. Confirm the real loop with people who work at the target; recruiters can misdescribe it.
   CLAIM(v4Dt4FalMOA@19:54)
5. Match drills to the role: UI components and front-end system design for UI loops; LeetCode
   only for generic SWE or backend loops where it is still asked.
   CLAIM(v4Dt4FalMOA@19:18)
6. Algorithms: learn theory first (a free university course plus algorithm channels), then
   200-300 problems on LeetCode and HackerRank filtered to your companies, grouped by pattern and
   data structure, then stop. CLAIM(2Xqu_GNvnxg@04:01) CLAIM(2Xqu_GNvnxg@04:52)
   CLAIM(2Xqu_GNvnxg@05:40) CLAIM(2Xqu_GNvnxg@05:30) CLAIM(2Xqu_GNvnxg@03:48)
7. Front-end coding: fundamentals of JavaScript, HTML, CSS and how the browser works; learn the
   platform mechanics (callback queue versus macro-task queue, how a page gets built); work the
   roughly 100-120 problem set on bfe.dev (about a month to close gaps); build small widgets in
   plain HTML/CSS/JS (a five-star rating widget is his example).
   CLAIM(2Xqu_GNvnxg@06:28) CLAIM(2Xqu_GNvnxg@06:49) CLAIM(2Xqu_GNvnxg@07:49)
   CLAIM(2Xqu_GNvnxg@08:15) CLAIM(2Xqu_GNvnxg@08:35)
8. System design: about three months, front-end system design first (API/backend design is a
   separate subject); prepare by cloning popular apps (Pinterest, Facebook, a chat app) in
   vanilla JS and understanding the mechanism behind each feature; go deep rather than staying
   safe (study the algorithm behind a masonry grid, build the hard features); when a concept is
   unclear, chase it to the source (a book on HTTP/2, learn Webpack if bundling is the gap).
   CLAIM(2Xqu_GNvnxg@13:08) CLAIM(2Xqu_GNvnxg@13:15) CLAIM(2Xqu_GNvnxg@10:08)
   CLAIM(2Xqu_GNvnxg@10:35) CLAIM(2Xqu_GNvnxg@11:03) CLAIM(2Xqu_GNvnxg@11:50)
   Then run the drills in fesd-interview-framework (references/mock-drill.md).
9. Behavioral: gather the common question list, prepare two true stories per question from real
   experience; never lie, and when there is no story say so and offer one on an adjacent topic.
   Expect roughly 50 common questions to write out and memorize when English is weak.
   CLAIM(2Xqu_GNvnxg@14:29) CLAIM(2Xqu_GNvnxg@16:07) CLAIM(2Xqu_GNvnxg@14:42)
   CLAIM(2Xqu_GNvnxg@15:07) CLAIM(v4Dt4FalMOA@16:08)
10. Language: for international companies invest in soft skills and English as hard as technical
    skill, because behavioral is the round most candidates lose; learn the interview vocabulary
    precisely ("conflict" means professional disagreement over an approach, not hostility);
    target B2 English for a comfortable pass, B1 only when speed matters.
    CLAIM(v4Dt4FalMOA@09:21) CLAIM(2Xqu_GNvnxg@16:15) CLAIM(2Xqu_GNvnxg@16:39)
    CLAIM(v4Dt4FalMOA@17:16)
11. Expect the campaign to run 6-7 months at 2-3 hours a day (algorithms 2-3 months, front-end
    coding about a month, system design about three months, behavioral 3-7 days), and expect
    doubt to peak at the end, not the start. Plan roughly 4-5 months of deliberate prep if the
    fundamentals are already there. CLAIM(2Xqu_GNvnxg@17:35) CLAIM(2Xqu_GNvnxg@18:00)
    CLAIM(v4Dt4FalMOA@00:44) CLAIM(v4Dt4FalMOA@01:14:52)
12. Résumé and access: put at least one recognized employer name on your CV, because big tech
    rarely auto-rejects candidates from known-strong talent pools; treat a referral as resume
    access only and expect to be scored like everyone else afterwards.
    CLAIM(v4Dt4FalMOA@04:47) CLAIM(v4Dt4FalMOA@12:21)
13. International career mechanics: choose a residency route that survives a layoff (he moved
    from a sponsored work visa to a UK talent visa: employer freedom, faster settlement and
    citizenship) and build the public evidence trail (articles, blog, talks, videos) before you
    need it; a talent-visa case can be assembled from about a year of public work.
    CLAIM(v4Dt4FalMOA@01:02:27) CLAIM(v4Dt4FalMOA@01:04:37)
14. Career window: learn languages and portable skills in your twenties, because after thirty
    family and responsibility crowd out the time.
    CLAIM(v4Dt4FalMOA@01:14:07)
