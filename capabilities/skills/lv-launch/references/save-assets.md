# Save assets: the reference comment

Saves are the strongest reported signal and the last unused high-weight one on this account. The move is to put the saveable artifact in a comment on the post, because links in the post body are penalized and the "link in first comment" workaround is penalized too.

Evidence it works here: one of Mike's own comments accumulated 242 impressions of its own, and in 2026 comments routinely draw more impressions than posts.

## What qualifies as a save

An answer key. A checklist. A decision table. A rubric graded green/amber/red. A one-paragraph definition of a term people get wrong. It must be deployable later: the working definition of a save is something a reader will want to deploy when they have more time.

## Rules

- Post it inside the golden hour, on his own post, framed as a reply to a real question.
- No external link in it. Inline the artifact; a link defeats the save and trips the link penalty.
- One reference comment per post. A second one is noise.
- Never pair it with engagement bait ("comment X and I'll DM you"): that construction is actively filtered and demoted.
- It carries no link-suppression risk as an author comment, which is why it is the safe place for the asset.

## The second save asset

One checklist comment is not the limit on saves. A graded answer key for the first asset (green / amber / red on each question, with the tell that separates the three) is a distinct asset people save for a different reason. It is the only write that raises the strongest signal again after publish, and it is the correct remaining lever when the delta series turns down.

## The repost that points at it

When a second distribution event is wanted, the "Add your thoughts" repost points at the save asset in its first comment, not at a link. Framing the repost around one commenter's story, credited by name, pulls that person and their audience back in. It is a public act on Mike's account: explicit yes first, and it is the only action that creates a new distribution event on an already-published post.

## What is banned here

- Engagement bait of any kind.
- Any external link in the asset or the comment carrying it.
- Two save assets in the same shape on the same post.
- Reporting a save-asset comment as posted on the strength of a click: verify by hard reload plus the string present exactly once.
