# Resume-only application packet

```text
status: READY_FOR_HUMAN_REVIEW
resume_sha256: sha256:<hash>
fit_decision: PURSUE
employment_rule: absent prior employer -> No; unsupported non-employment field -> NEEDS_MIKE
browser_state: not_started
final_submit: false
```

The packet contains a resume-derived employer list, a requirement-by-
requirement fit matrix with source references, a tailored resume, a specific
cover note, screening answers, and a human checklist. The target company is
never added to employment history merely because it is the target. A browser
prefill can end at Review; only Mike can submit.
