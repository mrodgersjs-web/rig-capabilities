Repetition with Variation (Ostinato) **Music:** A repeating pattern that evolves slightly each time. Same core idea, new element added each cycle (Ravel's *Bolero* — same melody for 15 minutes, orchestration changes every cycle). **Content:** Return to core themes but never say the same thing twice. Each revisit adds a new layer, angle, or depth. The audience should feel like they're hearing a familiar melody played by a bigger orchestra each time. ### 7. Call and Response
