# Aside sandbox rules (App Studio sub prompt, v1)

Contract
- id: app-sub-sandbox-rules | version: 1 | tier: sub | parent: app-studio-scaffold-setup | stage: scaffold-setup | audience: builder
- inputs: {{PORT_LO}}, {{PORT_HI}}
- output: a scaffold-setup record whose Evidence block shows the install flags, the port used and how each server was stopped
- lessons carried (each one is an instruction to follow):
  - LA-01: Confirm the toolchain avoids native .node binaries in the Aside sandbox: next --webpack, Tailwind v3, npm i --ignore-scripts, PGlite as a standalone service.
  - LA-02: Find PIDs with lsof -t on a file or port the process holds (ps, pgrep and pkill are blocked) and serve a fresh build on a fresh port instead of trusting :3000.
  - LA-03: Confirm exactly one builder runs for this project (no watcher routine or second agent building) and run long builds detached with nohup while polling the log.
  - LA-25: Curl the exact local URL for a 200 and the expected content before claiming a local surface is up; a keepalive supervisor does not prove liveness.
  - LA-32: Do not rely on an agent's own sandbox inside the Aside sandbox: run it in its configured mode with secrets scrubbed from its env, one folder in scope, and a hard time cap.
  - LA-33: Unset PYTHONHOME and PYTHONPATH before a child process starts a different Python, because the Aside runtime exports its own and the system python then dies with No module named encodings.
- gates: library gate app.prompt on this text; output gate app.stage-gate on the scaffold-setup record (a required noul passes only above 0.9; DEFERRED when the classifier is down, never a guessed verdict)
- done_when: `npm install --ignore-scripts` exits 0, the production server answers on a port in {{PORT_LO}}-{{PORT_HI}}, and `lsof -t -i :<port>` prints nothing after you stop it
- stop: report BLOCKED: <binary> when a required package only ships a native binary; deploy, git push, publish, purchase, emails to real people and paid API calls stay held for Mike's Gate-D approval

1. Native .node binaries are blocked: use next build --webpack and next dev --webpack, Tailwind v3 (never v4), and npm install --ignore-scripts (LA-01).
2. ps, pgrep and pkill are blocked: find a process with lsof -t -i :PORT and stop it with kill $(lsof -t -i :PORT) (LA-02).
3. Serve each fresh build on a fresh port in {{PORT_LO}}-{{PORT_HI}} and curl the exact URL; a running process is not proof (LA-25).
4. One build at a time, one builder per folder; run long builds detached and poll the log (LA-03).
5. Unset PYTHONHOME and PYTHONPATH before any tool starts its own Python (LA-33).
6. Your own sandbox flags do not nest inside this sandbox; stay inside the current folder (LA-32).

Evidence rule: a step counts as done only when its record shows the exact command, the exit code, and the observed output (status code, body excerpt, file hash or screenshot path). A plan, a stub, a description of the code or a green preview is not evidence.
