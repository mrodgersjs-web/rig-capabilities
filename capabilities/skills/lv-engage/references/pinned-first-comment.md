# Pinned first comment

Format doctrine adapted from the pinned-comment source, which is authored in a third-party creator's voice (Charlie Hills). Keep the mechanic; the persona, the banned-word list and the gold-standard example belong to that creator and are dropped [pinned-comment]. On Mike's lanes the pinned comment is optional personality on top of a post that already carries the value, and it is staged for Mike's approval like everything else.

## The mechanic

The visual gag carries the joke; the comment only captions it. So build the image first, then write the caption. If the caption is funny standing alone, the image is redundant; if the image needs the caption to land, the image is weak [pinned-comment].

1. **Find the admission.** Every suitable post hides one quiet, self-deprecating confession about the writer's working life. Name it in one sentence. If you cannot, the post is not pinned-comment material yet [pinned-comment].
2. **Build the image prompt first.** One clear visual gag the eye catches in under a second, played completely straight (no winking, no exaggerated poses), with the author as the lower-status figure: the tool wins, the deadline wins, the author loses with quiet dignity [pinned-comment].
3. **Caption it in exactly four lines.** Line 1 states the absurd scene as plain fact. Line 2 flips status downward. Line 3 is the smallest possible win. Line 4 lands resigned, without reaching for a punchline [pinned-comment].
4. **Run the five tests** before staging (below).

## Format rules

- Exactly four lines, one complete sentence each, kept short (about 40 characters per line) [pinned-comment].
- Line one opens with a pin marker; no PS, no hashtags, no em dashes, no semicolons [pinned-comment].
- Keep the register of the lane: on Lane A the warmth is Ted Lasso-shaped and Birch stays Tuesday-only; on Lane B a pinned comment is plain and evidence-led or it does not run [viral-core].

## The five tests

1. **Gag test:** describe the visual gag in five words. More than five means the image is busy.
2. **Caption test:** line 1 must caption the image as fact, not set up a separate joke.
3. **Status test:** the author is the lower-status figure in every line.
4. **Reach test:** line 4 must not strain for a punchline; resigned beats clever.
5. **Standalone test:** read the four lines without the image. Mild at best is correct, because the image does the work.

If any test fails, rewrite before staging [pinned-comment].

## Failure modes to reject

- A caption that merely restates the picture instead of reporting the scene [pinned-comment].
- The author winning, looking clever, or sounding authoritative in any line.
- More than one gag per image.
- Sponsored or product names jammed into the caption; the post body is where offers live.
- Any fabricated result, client, or metric inside the gag [viral-core].

## Output and gate

Produce, in order: the admission in one sentence, the full image prompt, the four-line caption, and a one-line note confirming the five tests passed. The caption is a comment and goes through the `comment.linkedin` Jev gate; the image prompt goes to the designated generator (Eden), not to an agent hand-authoring the asset [viral-core]. On Lane A this is staged and never published by an agent [personal-brand-lane].
