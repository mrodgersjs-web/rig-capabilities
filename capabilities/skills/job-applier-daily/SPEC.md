# Daily Job Applier 1.3.0 specification

Deliver a portable documentation and local-validation package extending Job Applier 1.2.2. Preserve its eight ordered leaves and full persona. Add daily admission, initiative research, separate participation/inclusion decisions, original-format resume and cover-letter writers, SlopMonster review, authoritative Airtable tracking, and bounded receipt reconciliation.

Given a new verified posting, when preparation runs, then all inherited leaves run in order with current source bindings, and every supporting step records actual outputs or an explicit hold.

Given employer research, when Mike's involvement is unknown, then research remains company evidence and a participation question; it cannot become his achievement.

Given a confirmed contribution, when inclusion is omitted or pending, then clean documents exclude it. Given approved documents, when specific application approval is absent, then submission remains held.

Given an uncertain tracker or ATS effect, when the workflow resumes, then it reconciles the original stable operation before any further mutation and never counts an unverified receipt.

Given the disabled default profile or missing adapters, when the package installs, then it activates nothing and reports unverified runtime capabilities. Local validator success proves only local checks.

See [acceptance](references/acceptance.md) for the fifteen required outcomes and adversarial cases. The final operational proof must come from real host/tool receipts, rendered artifacts, authenticated reviews, and independent verification. Native GrokBot import, live scheduling, Airtable access, and application submission remain unverified until observed.
