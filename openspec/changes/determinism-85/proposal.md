# Determinism 85 admission

## Why

Current process manifests can declare their own operations, execution kinds, taxonomy, and graph. A process can omit model work or add harmless code nodes and still appear deterministic. Current Gate-D records also do not authenticate the human hand or bind one exact effect.

## Change

Add a source-derived operation inventory before any D85 score. Then add authority-owned classification, exact path scoring, typed model-necessity validation, independent RED-to-GREEN proof, authenticated exact-action Gate-D, and one shared pre-tool rule for Claude Code, Hermes, OMP, and Prime-Agent.

## Current boundary

The first slice extracts reachable Python symbols, spans, local call edges, external call evidence, source hashes, and adapter bindings from a fixed registry. It compares a submitted inventory exactly and returns `INVENTORY_PASS` or `BLOCK`. Classification, scoring, Gate-D binding, wiring, and proof remain blocked.
