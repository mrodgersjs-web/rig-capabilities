# Audience design and connection requests

Who gets a request, what the request says, how many go out, and how a warm interaction turns
into a first message. Nothing here sends; everything stages for Gate-D.

## The daily engine (Clark, about 30-35 minutes)

- Connection requests: about 20 per weekday; he cites roughly 100 a week as the platform
  ceiling. Favor people with mutual connections and people who posted in the last 30 days
  (a Sales Navigator filter). Earlier Clark variants said 20-30 a day and 20-25 a day; the
  current figure is the one to plan on. [outbound-and-pipeline: w2_zVhExo1s, mJ1c1PHBoo4,
  Fvl_wMtcz24, 8VqGXuFxd3Q, gZwWBtiZ7qE]
- Send a connection request to every booked prospect before the call. [-WGCvECeTcU]
- Comments: five to ten thoughtful comments a day beat 20-50 lazy ones. Targets: buyers,
  the creators buyers follow, and competitors. Keep a sheet of 15-30 target accounts;
  15-20 minutes a day, 30 at most. If buyers never post, comment where they read.
  [SL8yfxUVFKE, mJ1c1PHBoo4, cWfOlNGZ6eg, szN0DF3Oqik]
- Review profile viewers daily; warm signals get the treatment in "Warm-signal routes" below.

## Blank note or note

Default is a blank connection request. "People just qualify you as a sales person if you
send a connection request note, whereas curiosity if it's empty leads them to accept it"
[creator, dm-sequences]. Clark agrees: no note unless you have actually met [outbound-and-pipeline].
A noted request is an override on the record: `connect_note_policy` requires a stated reason
so the variant is a decision, not a default someone forgot choosing [dm-sequences].

Note budget if a note is approved: a connect note that actually sent on this account was
180 characters; a 300-character note never reaches the field, so an over-budget note wastes
the slot [dm-scribe].

visible as the sources wrote them; a request for more volume does not lift a cap.

## Warm-signal routes (comment-to-dm)

When someone likes, comments on, or connects with a post, that is the highest-intent moment and
it is time-boxed: reach out "within 5 minutes" with a hyper-personalized note [creator]; treat
5 minutes as a claimed window, not a measured rate [comment-to-dm].

| they did | you do | owner |
|---|---|---|
| Commented on your post | Reply in-thread first, always; DM only if the thread needs the private half | golden-hour, then this stage |
| Liked your post, never spoke | Nothing immediately; next pass as a Tier 2 candidate | this stage |
| Commented on an in-topic post, or connected | Warm-open event; qualify on an artefact before drafting | this stage |

The DM continues the topic, never a pitch: reference the specific thing they said, add one thing
they did not, stop, and ask for a letter, not a call [comment-to-dm].

## Engagement ladder before the DM

Work public before private: monitor, micro-engage, value drops, then DM. Mix comments, shares
and DMs per target account weekly (3 comments, 2 value shares, 1 DM), engage within about 30
minutes of a prospect's activity when possible, and tie every outreach to proof. Move hot threads
to a call quickly and log the outcome [gtm-sales-prospecting-social-selling, synthesized].

## The drafted artifact (dm-scribe contract)

- Every outbound text is a staged draft stamped `status: "UNSENT"`, with a header carrying
  channel, measured character count, target slug, evidence refs, batch id [dm-scribe].
- Facts come only from the homework brief. A draft with no brief returns `blocked`; never fill a
  gap from model memory of a real person [dm-scribe].
- One cheap ask per draft. A stranger does not owe a call [dm-scribe].
- After a connect request, the profile shows a Message button while still second-degree; that
  never proves acceptance and never justifies a re-send. True Pending is visible only in the
  More menu [dm-scribe].
- Reply drafts must name the parent comment's author and `urn`; composers stack and persist, and
  a "first article containing this author's name" match can land a reply on the wrong parent
  [dm-scribe].
- Positive register only in public replies to Mike's content: validate, add one insight, link his
  post as a complement [dm-scribe].
