# Interactive lead magnet (one mechanism)

## Step 1. Define the transformation

One input (household income, matter type, revenue range, symptom duration) → one useful
personalized output (budget range, likely process steps + what to prepare, service-fit answer).
The output must be worth having with no email.

## Step 2. Spec the widget

- Prompt/what the tool computes (written as a verifiable rule, not a vague "AI magic")
- Input placeholder + single button ("see your estimate")
- Personalized output with honest reasoning and caveats (professional disclaimer where required)
- Email ask AFTER the output ("more like this"), optional — never the toll gate
- Leads export to the client's CRM with consent language the firm approved

## Step 3. Embed and route

Embed in the matching answer/comparison page (rig-revenue-money-pages, rig-revenue-answer-first).
The magnet itself is publishable content → rig-revenue-publish-gate. YMYL outputs (legal/financial/
medical ranges) get professional review before launch.

## Step 4. Variants

One magnet per page type and buyer stage; test variants on the button/ask copy. Static-download
magnets (checklists, fee guides) are the fallback where an interactive tool doesn't fit.
