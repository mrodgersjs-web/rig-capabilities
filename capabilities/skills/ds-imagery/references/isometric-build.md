# Isometric Build

Purpose: grid math, face drawing, one light, shadow, and layer naming (laws 1-10).

Load when: the task touches this part of imagery and art direction, or a ds-imagery critique names it. Part of `ds-imagery`.

## Checklist
1. Work through every law below against the current artifact before calling the sub-topic done.
2. Cite the CLAIM when a law drives a decision; a law you cannot cite is labeled own reasoning.

## Anti-patterns for this sub-topic
- Recording the isometric height change as an action. The action stores a fixed height, not 57.74 percent. CLAIM(eFHxknDs4Mk@01:16, eFHxknDs4Mk@01:56)
- Building a texture brush from a soft wash or from a file that still shows paper. CLAIM(dBmUQ1IWqX4@01:25, dBmUQ1IWqX4@02:00)
