# Résumé-grounded Hermes applications

## Why
Mike requires employment answers to use only his résumé. Existing generic skills include static personas and stale operational assumptions.

## What Changes
Add a focused Hermes skill, copyable prompt, source-bound employer baseline, answer/tracker templates and a local structured answer checker. Install only this new skill through the capability registry. Preserve existing skills and the original résumé.

## Impact
Local workflow and installation only. No job applications, account creation, recruiter messages, credential changes or browser form submissions occur in this build. The checker does not establish semantic truth or grant submission permission.
