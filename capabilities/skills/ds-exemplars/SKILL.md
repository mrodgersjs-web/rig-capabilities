# Looks like / does not (exemplars)

JEV FIRST, and it binds every task under this skill: an agent whose only context is this excerpt
sends semantic triage, routing and classification to the rig-s1gate Jev path BEFORE any frontier LLM call
(`~/.rig/bin/rig-s1gate check <rubric> --file <artifact> --subject "<kind> <id> sha256:<hash>" --json`).
When the classifier is unavailable: DEFERRED, never a guessed verdict. A required signal passes only above
0.9.

## Load surface
Load this skill FIRST for any judgment about whether design is good or bad. It is an always-loaded
task-start surface, not a deep reference an agent must already know about: the `/design-studio` command loads
`design-studio-os`, which names this skill as the calibration set; `ds-critic` and `ds-exemplar-retriever` load
it before any critique; and `ds-gate-critique` cannot pass a session without a named pair. Generated by
`tools/build_reference_skills.py`; pair cards by `studio-exemplars/scripts/build_pairs.py`.

## How to use
1. ds-exemplar-retriever picks the stage(s) the job touches (Jev jev.triage; DEFERRED falls back to the
   stage table and says so).
2. Read references/<stage>-pairs.md. Name the 2-4 pairs closest to the work.
3. In a critique, a finding that matches a does-not row cites that row's CLAIM.
4. A pair becomes a visual reference only after screenshots of both sides are captured locally and Jev
   ui.design scores the good side above the bad side. Third-party screenshots never enter a repo.
