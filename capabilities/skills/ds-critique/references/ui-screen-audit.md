# Ui Screen Audit

Purpose: login, form, action weight, desktop nav, and controls that must look clickable. Owns 6, 7, 16-19, 72, 83, 85-88.

Load when: the task touches this part of critique and quality gates, or a ds-critique critique names it. Part of `ds-critique`.

## Checklist
1. Work through every law below against the current artifact before calling the sub-topic done.
2. Cite the CLAIM when a law drives a decision; a law you cannot cite is labeled own reasoning.
3. Where creators disagree (see the SKILL.md), state both positions and test rather than assume.

## Anti-patterns for this sub-topic
- Two calls to action of equal size on a sign-in screen. CLAIM(XZf5A0wcruE@02:47)
- Hero that repeats the logo tagline. CLAIM(s9XlAUisl8Q@00:36)
- Decorative rules with no structural job, especially low-contrast rules on a saturated field. CLAIM(s9XlAUisl8Q@00:50)
- Thin gray type on red, or colored type on a photograph. CLAIM(s9XlAUisl8Q@01:10)
