# Cover letter writer

## Inputs
Exact employer/role, JD/persona, evidence ledger, initiative states and approved template if supplied.

## Actions
Explain fit using supported contributions and sourced target needs. Keep proposed future action future tense. Exclude unsupported metrics and participation. Create a Word letter with readable consistent formatting; do not invent a named recipient.

## Outputs
Tailored cover-letter DOCX, claim/source map, before/after edits and render manifest.

## Gates
Every personal assertion must have source scope. Participation and inclusion decisions apply to the letter separately where their scope differs.

## Recovery
Revise unsupported text and renew hash-bound reviews. Missing renderer holds final letter.
