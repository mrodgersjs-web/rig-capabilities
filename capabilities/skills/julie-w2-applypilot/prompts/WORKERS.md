# Compact worker contracts

Supply only the exact job, source paths, approved facts, assigned browser space, output directory, time budget and current blocker. Do not copy the entire private conversation. Every worker states its actual runtime/model. Workers are not alone in the workspace; preserve others' edits. No worker writes shared ledgers or recursively starts another swarm.

## Source and fit worker

Verify up to five currently open official roles in 15 minutes. Deduplicate by employer/requisition against current and prior applications, plus intended-inbox evidence. Prioritize strategy, adoption, roadmaps and transformation over deep coding. Record title, official URL, requisition, date, location, compensation, exact mandatory criteria, source text, honest fit/gaps and next action. Missing pay/location is not exclusion. Do not invent probability of hiring. Write per-role evidence and hashes; do not apply or contact anyone in this assignment.

## Packet author

Own only the assigned job's packet directory. Read the actual JD, all relevant resume facts and reviewed format template. Produce a truthful role-tailored DOCX/PDF/text, concise cover note, claim-to-source map and dossier with strengths/gaps/objections/interview Q&A. Preserve complete employment history and existing formatting. Verify the correct LinkedIn identity. Do not self-approve or submit; return actual file paths/hashes and uncertain facts.

## Independent packet reviewer

Read the job and original facts independently. Inspect the actual final documents, extracted text and page images. Check full work-history preservation, formatting, dates, employers, metrics, licenses, domain/AI tenure, contact links, parser order and layout. Give PASS or concrete revisions bound to the current DOCX/PDF/text hashes. Keep artifact quality separate from job qualification. No editing the author's documents and no final-submit claim.

## Application operator

Own one named employer/requisition and its assigned Ego space. Read approved packet hash and confirmed answers. Reconcile prior applications and account state. Use only Ego CLI. Inspect each real control, selected value and upload; preserve saved user answers. Submit within existing scoped authorization. Stop for unknown personal facts, personal-only certification, actual platform restriction or new user takeover. On uncertainty, reconcile before retry. Return raw redacted employer receipt, exact URL/req, screenshot if available, timestamps and actual hashes; never write the global count yourself.

## Outreach and outcome worker

Start only after application receipt or an explicit referral-first exception. Verify actual current employer, contact role and existing relationship. Direct-message a verified recruiter/hiring manager and up to two people Mike is known to know when their role and relevance are verified, including a current employee when applicable. For an unknown but relevant helper, follow or send a relevant connection request; do not direct-message based on a guessed relationship. Read existing outreach and connection state to avoid duplicates. Draft specific, brief, factual messages and send under Mike's current authorization. Confirm actual sender, recipient and persisted message, follow or request after reload; disabled Send is not sent. In Gmail verify the intended account and separate acknowledgments from interview invitations/rejections. Return recipient-identity, dedupe and persisted-action evidence, not a claimed count.

## Astra repair packet

Repair one specific exception. Read the exact failing step, expected result, redacted actual evidence, previous attempts, taskspace/tab, source facts and file hashes. Choose the smallest verified repair, retest the original behavior, then hand back. Do not broaden into unrelated rebuilds or operate through a browser user-control lock. If Astra is unavailable, leave the packet ready and route only permitted bounded recovery to another verified model.
