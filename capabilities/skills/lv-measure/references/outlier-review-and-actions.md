# Outlier review, flop diagnosis, and the action map

## Weekly outlier review (against the account's own baseline)

Review the last five or six posts against the account's own baseline, not against other creators, then
rank the formats and set next week's slate. A 100-like post on a 10-20-like baseline is the signal to
study; chasing likes is a trap because the target is customers [distribution-and-algorithm].

Threshold rules from the P3 runner: an outlier at 5x or more of the rolling baseline promotes its hook
pattern into the hook library with the evidence attached; a pattern below half the baseline twice is a
dead-pattern candidate; three appearances without beating baseline is worth burying. A recycled format
on its fourth cycle is a treadmill and gets named out loud. Outliers and dead patterns are the two
outputs of the review; the hook library only ever receives measured winners [li-measurement,
li-measurement-steward, measurement-kpi-loop].

## Flop diagnosis (check in this order)

1. Opening: two or three hook levers in lines 1-3?
2. Media: a real photo with people in it?
3. Story: is each take paired with one?
4. Intensity: turned up about 20%?
5. Timing: a weekday mid-morning?
6. Audience ceiling: engineering, procurement and IT buyers read but rarely react; founder, marketing
   and sales audiences react. Set the benchmark before blaming the content.
7. Topic reach: when niche posts stall, widen within the buyer's world, never into empty controversy.
8. Engagers: are the people reacting actually buyers?

The cause call is a typed judgment: run it through Jev (stage mandate) and report DEFERRED rather than
guessing when no rubric covers it. The order above is the deterministic checklist the judgment works
from [distribution-and-algorithm].

## The action map (every number drives exactly one action)

| Observation | Action |
|---|---|
| post beat baseline clearly | rerun: bank it and schedule a verbatim rerun (proven winners at about 3 months; the origin story quarterly) |
| hook under-performed but the idea held | rewrite the hook (and the opening only: the image cannot be swapped after upload) |
| good copy, weak media | change the media; re-test with a real photo first |
| format lost twice after one re-cut | retire the format for now; formats cycle anyway |
| ICP-relevant post under-delivered | propose a boost for Mike's approval: Gate-D item, named dollar amount inside the $300 total cap, PS-line link added before boosting |
| metric moved with no cause | report correlation, change nothing, watch the next 10 posts |
| nothing measurable this week | record null; do not manufacture a learning |

Boost mechanics if Mike approves: let the post run organically first, boost proven winners or
ICP-relevant under-performers, edit a PS line with the link in first (boosted posts run on awareness or
engagement objectives, so the PS is the only call to action), target with an uploaded company list, feed
paid engagers back into outreach, and mine the ad demographics report for target accounts
[distribution-and-algorithm].

## What the review refuses to do

- Never invent a number, a client, a quote or a result to make a pattern look cleaner.
- Never call a tactic a winner before the evidence bar (about 10 posts carrying it).
- Never extrapolate a rising curve linearly; decay beats extrapolation (a growth rate roughly halved
  inside the final twenty minutes of one observation window) [lg-measure].
- Never report a broken analytics transport as zero engagement; transport-zero and engagement-zero are
  different truths and conflating them has already cost this estate days of misdiagnosis
  [li-measurement-steward].
- A morning red on the daily scorecard is not a failed runner: engagement windows fire later
  [metrics-scorecard].
